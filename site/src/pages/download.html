Install over USB (recommended)

  1. Connect the X4 Pro to your computer with a USB-C cable, then wake and unlock it.
  2. In Chrome or Edge, open the CrossPoint web flasher and choose Xteink X4Pro.
  3. Click Custom .bin, choose the file you downloaded, and start the flash. Keep the cable connected until it finishes and the reader restarts.

If the browser's device picker does not list the reader, try another USB port or cable first. The CrossPoint README explains what to do with a USB-locked device.

Update from the SD card

  1. Rename the download to firmware.bin and copy it to the root of the SD card.
  2. On the reader, open Settings → System → SD Card Firmware Update.

Note

Check for Updates on the reader installs the latest upstream CrossPoint release, which replaces nexlibrOS. Update nexlibrOS from this page instead.

Apps and books

The firmware does not include the Lua apps: copy them to /apps/ on the SD card from the Apps page. Put books anywhere on the card, or send them with the File Transfer screen.

Going back

To return to CrossPoint, flash an official release the same way. Your books, settings and reading progress live on the SD card and are kept.
